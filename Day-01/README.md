# Day 1 – Dataset Selection & Import

## Selected Dataset

**Employee Details Dataset**

File: `Employee-Details-Day01.xlsx`

## Task

Selected the Employee Details dataset and imported it into Microsoft Excel for data analysis practice.

## Dataset Overview

- Records: 150 employees
- Columns: 9
- Main Sheet: Raw Dataset
- Working Sheet: Day-1-Clean Dataset

## Key Observations

1. The dataset contains 150 employee records and 9 columns.
2. The dataset contains different data types, including text, numerical values, and dates.
3. Important fields include Employee ID, Name, Department, Country, Salary, Date of Joining, Performance Rating, Gender, and Email.
4. Some fields contain missing or blank values, which may need to be handled during later data-cleaning stages.

## Conclusion

The Employee Details dataset is suitable for practicing Excel data analysis, data cleaning, formulas, PivotTables, charts, and dashboard creation.
