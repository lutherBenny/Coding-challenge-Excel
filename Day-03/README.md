# Day 3 – Basic Excel Formulas (Part 1)

## Task

Created a summary table using basic Excel formulas to analyze the E-Commerce dataset.

## Formulas Used

- SUM() – Calculates the total.
- AVERAGE() – Calculates the average.
- MIN() – Finds the minimum value.
- MAX() – Finds the maximum value.
- COUNT() – Counts numeric values.

## Summary

Analyzed the following columns:

- Sales
- Quantity
- Profit

## Key Observations

- Total Sales: 11,440,574
- Average Sales: 246
- Maximum Sales: 22,638
- Total Quantity: 161,960
- Total Profit: 1,516,156
- Average Profit: 32

## Skills Practiced

Excel SUM, AVERAGE, MIN, MAX, and COUNT functions.
