# Day 3 – Basic Excel Formulas (Part 1)

## Task

Practiced basic Excel formulas using the Employee Details dataset.

## Formulas Used

- SUM()
- AVERAGE()
- MIN()
- MAX()
- COUNT()

## Work Completed

- Created a summary table in the Day-3 Clean Dataset sheet.
- Calculated the total Salary using SUM().
- Calculated the average Salary using AVERAGE().
- Identified the minimum Salary using MIN().
- Identified the maximum Salary using MAX().
- Counted numeric Salary values using COUNT().
- Calculated total, average, minimum, maximum, and count for Performance Rating.

## Summary Results

### Performance Rating

- Total: 359
- Average: 2.872
- Minimum: 1

## Observations

1. The SUM function was used to calculate the total Salary and Performance Rating.
2. The AVERAGE function was used to calculate the average Salary and Performance Rating.
3. The MIN and MAX functions were used to identify the minimum and maximum values.
4. The COUNT function counted the numeric values in the Salary and Performance Rating columns.
