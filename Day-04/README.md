# Day 4 – Basic Excel Formulas (Part 2)

## Task

Practiced conditional Excel formulas using the Employee Details dataset.

## Formulas Used

- IF()
- COUNTIF()
- SUMIF()
- AVERAGEIF()

## Work Completed

- Used IF() to categorize employees based on salary.
- Used COUNTIF() to count employees based on specific conditions.
- Used SUMIF() to calculate the total salary for employees in the IT department.
- Used AVERAGEIF() to calculate the average salary for employees in the IT department.
- Created multiple conditions to practice conditional calculations.

## Conditions Used

1. Salary >= 70000
2. Performance Rating >= 4
3. Department = IT

## Observations

1. The IF function was used to categorize employees based on their salary.
2. The COUNTIF function was used to count employees based on specific conditions.
3. The SUMIF function was used to calculate the total salary for employees in the IT department.
4. The AVERAGEIF function was used to calculate the average salary for employees in the IT department.
