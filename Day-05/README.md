# Day 5 – Text Functions Practice

## Task

Practiced text functions using the Employee Details dataset to clean and format text data.

## Functions Used

- LEFT()
- RIGHT()
- MID()
- UPPER()
- LOWER()
- PROPER()

## Work Completed

- Used LEFT() to extract characters from the beginning of employee names.
- Used RIGHT() to extract characters from the end of employee names.
- Used MID() to extract characters from the middle of employee names.
- Used UPPER() to convert employee names to uppercase.
- Used LOWER() to convert department names to lowercase.
- Used PROPER() to format department names with proper capitalization.

## Observations

1. The LEFT function was used to extract characters from the beginning of employee names.
2. The RIGHT function was used to extract characters from the end of employee names.
3. The MID function was used to extract characters from the middle of employee names.
4. The UPPER, LOWER, and PROPER functions were used to format text consistently.

## Conclusion

The Day 5 exercise helped me practice Excel text functions for extracting and formatting employee data.
