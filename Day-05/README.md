# Day 5 – Text Functions Practice

## Task

Practiced Excel text functions to clean, format, and extract information from the E-Commerce dataset.

## Text Functions Used

- PROPER()
- UPPER()
- LOWER()
- LEFT()
- MID()
- RIGHT()

## Work Completed

- Used PROPER() to format customer names.
- Used UPPER() to convert country names into uppercase.
- Used LOWER() to convert country names into lowercase.
- Used LEFT() to extract the day from Order Date.
- Used MID() to extract the month from Order Date.
- Used RIGHT() to extract the year from Order Date.

## Observations

1. PROPER() can format customer names with the first letter of each word in uppercase.
2. UPPER() converts country names into uppercase letters.
3. LOWER() converts country names into lowercase letters.
4. LEFT(), MID(), and RIGHT() can extract specific parts of an Order Date.

## Conclusion

The Day 5 exercise helped me practice Excel text functions for formatting and extracting information from data.
