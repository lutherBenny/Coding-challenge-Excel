# Day 6 – Data Validation & Cleaning Intro

## Task

Cleaned and validated the Employee Details dataset by checking for duplicates, missing values, and inconsistent data.

## Work Completed

- Checked the dataset for duplicate records.
- No duplicate records were found.
- Identified and handled blank Name values.
- Identified and handled blank Department values.
- Identified and handled blank Country values.
- Handled missing Salary values represented as `N/A`.
- Identified and handled blank Date of Joining values.
- Identified and handled blank Performance Rating values.
- Identified and handled blank Gender values.
- Identified invalid Email values and replaced them with `Unknown`.

## Data Cleaning

Missing and invalid values were handled using `Unknown` where the original value was unavailable or invalid.

## Observations

1. No duplicate records were found in the dataset.
2. Blank Name, Department, Country, Date of Joining, Performance Rating, and Gender values were identified and handled using `Unknown`.
3. Missing Salary values represented as `N/A` were handled using `Unknown`.
4. Invalid Email values were identified and replaced with `Unknown`.

## Conclusion

The Day 6 exercise helped me practice data validation and cleaning by identifying duplicates, missing values, and inconsistent data in the Employee Details dataset.
