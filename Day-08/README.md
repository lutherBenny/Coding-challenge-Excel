# Day 8 – Handling Inconsistent Data

## Task

Cleaned and formatted the Employee Details dataset using Text to Columns, TRIM(), and Flash Fill.

## Functions and Features Used

- Text to Columns
- TRIM()
- Flash Fill

## Work Completed

- Used Text to Columns to split the Name column into First Name and Last Name.
- Used TRIM() to remove unnecessary spaces from the Name values.
- Used Flash Fill to automatically extract First Names based on the identified pattern.
- Organized the text data into separate columns for easier analysis.

## Observations

1. The Text to Columns feature was used to split the Name column into First Name and Last Name.
2. The TRIM function was used to remove unnecessary spaces from the Name values.
3. Flash Fill was used to automatically extract First Names based on the given pattern.
4. The text data was cleaned and organized into separate columns for easier analysis.

## Conclusion

The Day 8 exercise helped me practice text cleaning and transformation techniques in Excel using Text to Columns, TRIM(), and Flash Fill.
