# Day 9 – Conditional Formatting for Data Cleaning

## Task

Used Conditional Formatting to visually identify missing, duplicate, and potential outlier values in the Employee Details dataset.

## Work Completed

- Used Conditional Formatting to highlight `Unknown` values representing missing or unavailable data.
- Checked the Employee ID column for duplicate values.
- No duplicate Employee IDs were found.
- Highlighted Salary values greater than 90,000 as potential high-value outliers.
- Used color-based rules to make data-quality issues easier to identify visually.

## Conditional Formatting Rules Used

1. Highlighted `Unknown` values.
2. Checked duplicate Employee IDs.
3. Highlighted Salary values greater than 90,000.

## Observations

1. Conditional Formatting was used to visually highlight missing or unavailable values represented by `Unknown`.
2. Duplicate values were checked in the Employee ID column, and no duplicate Employee IDs were found.
3. Salary values greater than 90,000 were highlighted to flag potential high-value outliers.
4. Color-based formatting made potential data-quality issues easier to identify visually.
