# Day 10 – Descriptive Statistics

## Task

Used the Analysis ToolPak to generate descriptive statistics for numeric columns in the Employee Details dataset.

## Work Completed

- Used Data Analysis → Descriptive Statistics for Salary.
- Used a numeric-only Salary helper column to exclude `Unknown` values.
- Used Data Analysis → Descriptive Statistics for Performance Rating.
- Used a numeric-only Performance Rating helper column to exclude `Unknown` values.
- Generated the Mean, Median, and Standard Deviation for both numeric columns.
- Combined the Salary and Performance Rating results into one worksheet named `Day-10 Descriptive Statistics`.

## Results

### Salary

- Mean: 66,280.93
- Median: 66,637
- Standard Deviation: 21,632.65
- Numeric Count: 142

### Performance Rating

- Mean: 2.872
- Median: 3
- Standard Deviation: 1.4432
- Numeric Count: 125

## Observations

1. Descriptive Statistics was generated for the Salary column using the Analysis ToolPak.
2. The Salary data had a Mean of 66,280.93 and a Median of 66,637.
3. The Standard Deviation of Salary was 21,632.65, based on 142 numeric salary values.
4. Descriptive Statistics was also generated for Performance Rating, with a Mean of 2.872, Median of 3, and Standard Deviation of 1.4432.

## Conclusion

The Day 10 exercise helped me practice using the Analysis ToolPak to calculate descriptive statistics and understand summary measures for numeric employee data.
