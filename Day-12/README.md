# Day 12 – Date & Time Functions

## Task

Practiced Date & Time functions using the Employee Details dataset to calculate date information and years of service.

## Functions Used

- TODAY()
- NOW()
- YEAR()
- MONTH()
- WEEKDAY()
- DATEDIF()

## Work Completed

- Used TODAY() to display the current date.
- Used NOW() to display the current date and time.
- Used YEAR() to extract the joining year from Date of Joining.
- Used MONTH() to extract the joining month from Date of Joining.
- Used WEEKDAY() to calculate the weekday value from Date of Joining.
- Used DATEDIF() with TODAY() to calculate completed years of service.
- Handled `Unknown` values in the Date of Joining column without producing errors.

## Observations

1. TODAY() was used to display the current date.
2. NOW() was used to display the current date and time.
3. YEAR(), MONTH(), and WEEKDAY() were used to extract year, month, and weekday values from Date of Joining.
4. DATEDIF() was used with TODAY() to calculate completed years of service, while Unknown values were handled separately.

## Conclusion

The Day 12 exercise helped me practice Excel Date & Time functions and calculate useful information from employee joining dates.
