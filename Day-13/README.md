# Day 13 – Lookup & Reference Functions (Part 1)

## Task

Practiced the VLOOKUP() function using the Employee Details dataset.

## Function Used

- VLOOKUP()

## Work Completed

- Created a separate Day-13 VLOOKUP sheet.
- Used Employee ID as the lookup value.
- Used VLOOKUP() to retrieve employee details from the Day-13 Clean Dataset.
- Retrieved Name, Department, Country, Salary, Date of Joining, Performance Rating, Gender, and Email.
- Applied VLOOKUP() across the dataset to duplicate the employee details.
- Kept Unknown values where the original dataset contained Unknown values.

## Observations

1. VLOOKUP() was used to retrieve employee details based on Employee ID.
2. Employee Name, Department, Country, Salary, Date of Joining, Performance Rating, Gender, and Email were retrieved from the Day-13 Clean Dataset.
3. The VLOOKUP results matched the corresponding Employee IDs in the original dataset.
4. Unknown values were retained where the source dataset contained Unknown values.

## Conclusion

The Day 13 exercise helped me practice the VLOOKUP() function and understand how lookup functions can be used to retrieve and duplicate related data from a dataset.
